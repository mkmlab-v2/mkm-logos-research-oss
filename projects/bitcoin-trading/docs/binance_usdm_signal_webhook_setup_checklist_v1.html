① Signal Bot · 웹훅 URL 받는 법

웹훅 URL은 계정·지역·제품명에 따라 화면이 다릅니다. 아래를 순서대로 시도하세요.

  1. 로그인 — 반드시 본인 계정(웹 또는 앱).
  2. Trading Bots 허브 — binance.com/…/trading-bots → 상단 Futures 탭. 그리드·DCA 등만 보이면 “More bots” / 앱에서 Signal·외부 시그널 류를 찾습니다.
  3. 선물 차트 쪽 — USDⓈ-M 선물 상단 메뉴의 Trading Bots 등으로 들어가, Webhook / Signal / External / TradingView 키워드가 있는 봇 생성 마법사를 연다.
  4. 마법사 안에서 심볼(예: BTCUSDT)·선물(USDⓈ-M)·레버리지·주문 방식을 정한 뒤, “Webhook URL” / “Copy URL” / “웹훅 주소”가 나오는 화면까지 진행한다. (한 번에 안 보이면 단계를 끝까지 넘긴다.)
  5. 앱에서만 노출되는 경우 — 웹과 메뉴가 다를 수 있으니 동일하게 Futures → 봇·시그널 메뉴를 찾는다.
  6. 못 찾겠으면 바이낸스 고객지원 검색창에 futures signal bot webhook 등으로 검색하거나, 채팅 지원에 “USD-M Futures에서 외부 웹훅 URL을 주는 봇 메뉴”를 문의한다.

URL은 비밀에 가깝게 취급합니다. 복사 후 채팅·이메일에 붙이지 말고, 아래 ②에서만 PC에 저장하세요.

② Webhook URL 저장 Security Agent 우선

  1. UI에서 복사한 URL을 저장합니다. Git에는 넣지 않습니다.
  2. 변수명: BINANCE_USDM_SIGNAL_WEBHOOK_URL (선택 시크릿: BINANCE_USDM_SIGNAL_WEBHOOK_SECRET)
  3. Windows 본선 권장: DPAPI 스토어에 동일 키 이름으로 저장 — scripts/Invoke-EncryptedSecretStore.ps1 · scripts/security_agent_manager.py (CONSTITUTION §1.1.2). PoC는 Security Agent → 환경 변수 → .env 순으로 읽습니다.
  4. BINANCE_KEY_SOURCE_MODE = auto | dotenv_only | env_only (API 키와 동일 라우팅)
# 예: Linux VPS 프로세스 env
export BINANCE_USDM_SIGNAL_WEBHOOK_URL="https://..."

# 예: PowerShell DPAPI set (레포 루트에서)
powershell -File scripts/Invoke-EncryptedSecretStore.ps1 -Action set `
  -Key BINANCE_USDM_SIGNAL_WEBHOOK_URL -Value "https://…"

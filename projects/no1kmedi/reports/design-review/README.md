# Design Review Screenshot Naming

- Keep baseline files as:
  - `no1kmedi-home-390-final.png`
  - `no1kmedi-home-768-final.png`
  - `no1kmedi-home-1440-final.png`
- For new revisions, append date and short tag:
  - `no1kmedi-home-390-YYYYMMDD-<tag>.png`
  - `no1kmedi-home-768-YYYYMMDD-<tag>.png`
  - `no1kmedi-home-1440-YYYYMMDD-<tag>.png`
- Use the same `<tag>` for all three widths in one review set.

## 🔄 업데이트 방법

### 자동 업데이트

```bash
python docs/verified_knowledge_base/update_all.py
```

이 스크립트는:
1. 통일장이론 데이터를 코드베이스에서 추출
2. 명리학 데이터를 검증된 기준일에서 추출
3. 성경 데이터를 English Trinity 소스에서 확인
4. 모든 데이터를 JSON 형식으로 저장

### 수동 업데이트

각 폴더의 JSON 파일을 직접 수정할 수 있지만, **검증된 데이터만** 포함해야 합니다.

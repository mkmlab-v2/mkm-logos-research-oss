## 🎯 업로드 전 준비

### 1. 자동 업데이트 실행

```bash
python docs/verified_knowledge_base/update_all.py
```

이 스크립트는:
- 통일장이론 데이터를 코드베이스에서 추출
- 명리학 데이터를 검증된 기준일에서 추출
- 성경 데이터를 English Trinity 소스에서 확인

## 📤 제미나이 JAMS 업로드

### 방법 1: 메인 파일 + 첨부파일

1. **메인 파일**: `docs/gemini/master_reference_prompt_final.md` 업로드
2. **첨부파일**: 이 폴더의 모든 JSON 파일을 첨부
   - `unified_field_theory/*.json`
   - `myeongri/*.json`
   - `bible/*.json`

### 방법 2: 통합 파일 생성 (권장)

제미나이 JAMS는 단일 파일 업로드를 선호하므로, 모든 JSON을 하나의 마크다운 파일로 통합:

```bash
# 통합 파일 생성 스크립트 (향후 구현)
python docs/verified_knowledge_base/create_integrated_file.py
```

## 📤 노트북LM 업로드

### 방법 1: Source 추가

1. 노트북LM에서 새 Source 추가
2. 이 폴더의 모든 파일을 Source로 추가
3. 업데이트 시 재업로드

### 방법 2: 폴더 업로드

1. 이 폴더 전체를 압축
2. 노트북LM에 업로드
3. 업데이트 시 재압축 후 재업로드

## 🔄 지속적 업데이트

### 자동 업데이트 설정

코드베이스 변경 시 자동으로 업데이트하려면:

1. **GitHub Actions** (향후 구현)
2. **로컬 스크립트**: 주기적으로 `update_all.py` 실행
3. **수동 업데이트**: 필요 시 수동 실행

### 업데이트 확인

`update_summary.json` 파일을 확인하여 마지막 업데이트 시간 확인:

```json
{
  "last_updated": "2026-02-10T02:22:48",
  "status": "success",
  "updated_files": [...]
}
```

# 명리 대외 서술 — 현대공학·데이터 어휘 가이드 (v1)

**작성일**: 2026-05-02  
**목적**: 내부 구현·스키마·코드는 **명리 도메인 용어·SSOT를 유지**하고, **상용 카피·학술 논문 서술·대외 제안·광고** 등에서는 미신적 인상을 줄이기 위해 **공학·데이터 과학 톤**으로 번역할 때의 기준을 고정한다.  
**상위 팩트**: `docs/final/CONSTITUTION_INFERENCE_IMPLEMENTATION_FACTS.md` · 내부 통찰 스트림 `docs/final/MYEONGRI_INSIGHT_SSOT.md` (역할 분리).  
**금지**: 용어만 바꿔 **과학적 검증·인과·수익을 단정**하는 표현. 산출·한계는 **조건부·아티팩트 근거** 형태를 유지한다(루트 Fact-Lock 정합).

## 3. 번역 테이블 (내부 → 대외)

내부 용어는 코드·문서 SSOT와 동일하게 유지한다. 오른쪽은 **대외 설명용 권장군**이며, 제품별로 하나씩 고정하면 된다.

| 내부(도메인) | 대외 1순위 (공학·데이터) | 비고 |
|----------------|-------------------------|------|
| 명리 / 만세력 파이프라인 | **역법·절기 정렬이 있는 캘린더 매핑 엔진**, 생시 기준 **타임라인 인덱싱** | 천문 근사(Meeus 등)를 쓸 때만 “천문 근사” 명시 |
| 사주(四柱) | **네 축 시각 특성 벡터**(연·월·일·시 슬롯) | “운명” 대신 “인코딩된 입력 특성” |
| 간지 | **순환 심볼 쌍**(간·지 인덱스), **이름 붙은 카테고리 축** | 필요 시 학술 각주에 干支 |
| 오행 | **다채널 가중·상호작용 모델**(5채널 스칼라 또는 벡터) | 물리 원소와 동일시 금지 |
| 대운 | **연령 구간별 컨텍스트 세그먼트**(예: 10년 단위 슬롯), **타임라인 상 상태 전이** | “운세” 대신 “구간별 요약 입력” |
| 세운 | **연 단위 세그먼트** / 연간 슬롯 | |
| 起運 | **첫 세그먼트 시작점의 연령 오프셋**(기준 시각 대비) | 절기 간 일수 기반일 때만 그 근거 한 줄 |
| 융합 (4D·rule_school 등) | **다중 소스 스코어 결합**, **가중 규칙 기반 융합**, **벡터 블렌드** | 단일 진리 아님을 문장으로 병기 |
| 지장간 | **지지 하위 채널 분해**(hidden stems / secondary weights) | |
| 조율자 / Coordinator | **정책 조율 레이어**, **가중치·게이트 조합 규칙** | “영적 중재”류 표현 금지 |
| 벡터·λ·게이트 | **특성 벡터**, **혼합 계수**, **통과/보류 이진 규칙** | 수학 기호는 문서 수식으로 분리 가능 |

## 4. 문장 패턴 (예시)

- 내부: “대운이 정해지면 그 구간에서 오행 가중이 바뀐다.”  
  대외: “연령 세그먼트가 바뀔 때 모델 입력 특성 가중이 갱신된다.”

- 내부: “명리 융합으로 최종 4D를 낸다.”  
  대외: “여러 규칙 기반 표현을 하나의 특성 벡터로 융합한다; 출력은 **정의된 스키마·산출 JSON**로 검증 가능하다.”

## 2. MKM ↔ 자연생태농원 상호 세금계산서

### 2.1 합법적·실무적으로 방어 가능한 거래

| 방향 | 내용 | 조건 |
|------|------|------|
| **MKM → 자연생태농원** | 실제 **노지심 SI·라이선스·온보딩·연동** | 계약·산출물(계정·로그·SOW) · **시가** · 특수관계면 공고·세무사 고지 |
| **자연생태농원 → 고객** | L1 위탁·L3 설치·시공 **실서비스** | 블로그 300만·설치 700~800만과 **상품 실체** 일치 · L1↔L2 자동 이중청구 금지 |
| **큐빅스 → 최종 구매자** | IoT HW | **공급받는 자 = 보조 신청인(개인 또는 장비 소유 법인)** · MKM 명의 위장 금지 |
| **MKM → 개인(신청인)** | SW만 (C04) | HW·임대료·배관 **발행 금지** |

### 2.2 부당·고위험 (설명만 · 실행 레시피 없음)

| 패턴 | 왜 위험한가 |
|------|-------------|
| **순환 계산서** (A→B→A 또는 A→B→C→A로 CAPEX만 키움) | 실물·용역 없이 **사업비 인정액만 부풀림** → 정산·환수·허위청구 이슈. 「상호 발행이니까 매출이 생긴다」는 **보조금 유리 논리가 아님**. |
| **MKM이 공급하지 않는 HW를 계산서** | 명의 위장(C08). 큐빅스 견적·계약·이체와 **4종 불일치**. |
| **동일 IoT 스택을 양 법인(또는 개인+법인)이 각각 보조 청구** | C09 이중 청구. 현장 사진·일련번호·설치지로 **교차검증**됨. |
| **특수관계 마크업만 있고 산출물 없음** | 「시가」가 아니라 **보조 한도 채우기**. 관련자 거래·부당이득 심사. |
| **「유리한 구도」용 가짜 가치** | 세금계산서는 **증빙**이지 **가치 창조 장치**가 아님. 공급가·부가세 분리·공고 상한만 본다. |

**상호 계산서가 「유리」한가?**  
→ **실제 SW/SI를 시가로 팔 때**만 정상 매출·비용 구조다.  
→ **농가 보조 CAPEX를 불리게/유리하게 조작**하는 수단으로는 **쓰지 않는다**. 오히려 관련자·순환으로 **불리**해진다.

## 4. 권장 클린 구조 (3안 · 자산당 수혜자 1인)

### 원칙 (공통)

- **물리 자산 1개 = 보조 신청인 1명(또는 1법인).**  
- 큐빅스 HW 계산서의 **공급받는 자** = 그 신청인.  
- MKM은 **SW만** · CAPEX 체인에 HW를 올리지 않음.  
- 개인 신청과 법인 신청이 **같은 일련번호 장비**를 공유하지 않음.

### 옵션 A — 개인 중심 (현 SSOT 격벽과 가장 정합) ★권장 기본

| 역할 | 주체 |
|------|------|
| 농가·후계자 보조 신청인 · HW 구매자 · 임차인 | **개인 이기륜** |
| SW/SI 계산서 | **MKM → 개인** (실제공급·시가) |
| L1/L3 영업 | **자연생태농원** (보조 CAPEX 밖) |
| HW 공급 | **큐빅스 → 개인** |

자연생태농원은 **이 Phase 1 자산으로 농가형 보조를 신청하지 않음.**

### 옵션 B — 법인 중심 (법인 적격·장부 소유가 맞을 때만)

| 역할 | 주체 |
|------|------|
| 농업회사법인 보조 신청인 · HW 장부 | **자연생태농원** (공고상 법인 적격 `[VERIFY]`) |
| SW/SI | **MKM → 자연생태농원** (시가·산출물) |
| 개인 이기륜 | **동일 자산에 대해 농가 보조 미신청** · 경영·노동만 |

토지·임대가 **개인 명의**인데 법인만 보조받는 구조는 **명의 불일치** `[VERIFY]` — 세무사·군 담당 확인 전 채택 금지.

### 옵션 C — MKM을 농가 보조 CAPEX 체인에서 완전 제외

| 역할 | 주체 |
|------|------|
| HW·배관·시설 보조 | 개인 **또는** 법인 **하나만** |
| MKM | 보조사업비 **밖** 구독·SI (C05에 가깝게 취급) · 또는 보조 종료 후 별도 계약 |

심사·특수관계 마찰을 **최소화**할 때 유리. MKM 매출은 보조와 **의도적으로 분리**.

### 한 줄 선택 가이드

| 상황 | 선택 |
|------|------|
| 상가리 179-1·임업후계자·경영체가 **개인** 중심 | **A** |
| 법인이 토지·장비·공고 적격을 **명확히** 갖고, 개인은 중복 미신청 | **B** (서류 Lock 후) |
| 특수관계·심사 리스크를 최우선 회피 | **C** |

**동시에 A+B로 같은 IoT를 청구하지 말 것.**

## 5. 지휘관 Q&A 스타일 결론

### 문제점 있나?

**Yes.**

1. **이중 신청 리스크** — 개인(경영체/후계자)과 자연생태농원이 같은 프로젝트·장비를 동시에 올리면 C09.  
2. **정체성 겹침 `[VERIFY]`** — 이기륜 = MKM 대표 + 경영체/임차인; 법인과의 실소유 관계가 불투명하면 관련자·명의 이슈.  
3. **상호 계산서 유혹** — 「서로 매출 내면 보조금에 유리」는 **오해**; 순환·부풀리기는 환수.  
4. **MKM CAPEX 0 격벽 붕괴** — HW를 MKM 계산서로 포장(C08).  
5. **L1/L2/L3·보조 CAPEX 합선** — 300만 위탁·99k 구독·시설비를 한 스토리로 9천만 포장.  
6. **공고 PDF 미Lock** — 인정 품목·부가세·특수관계 규칙이 아직 템플릿 (`subsidy_cost_eligibility_wall`).

### 세금계산서로 유리한가?

- **실체 있는 SW/SI를 시가로** MKM이 공급하고, 공고가 SW를 인정하면 → **정상 증빙**으로서만 「유리」(인정 후보).

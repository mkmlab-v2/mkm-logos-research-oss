## 2. 실내·시설 스마트팜 “비싸기만 하고 이득이 적다” — 원인 분해

지휘관이 본 뉴스 유형은 보통 **(A) 시설원예 스마트팜 경제성 불만**과 **(B) 수직농장/식물공장 에너지 실패**가 섞인다. 둘 다 “설치비만 비싸다”로 요약되지만 **메커니즘이 다르다**.

### 2.1 시설원예(유리·비닐+ICT) — 국내 현장 불만 `[FACT]`

| 원인 | 증거·설명 | 출처 예 |
|------|-----------|---------|
| **초기 CAPEX** | ha당 하이테크 온실 **15~35억** 등 추정 · 자부담만 수억 | 농수축산신문 Issue+ (이문행 교수 발표 인용) |
| **투자 대비 성과 불확실** | 익산 농가 조사: 도입 의향 **35%** vs 부정 **65%** · 최대 우려 = **투자비용 대비 낮은 성과** | 프레시안/KREI 익산 용역 (2024) |
| **설치비 확보 난** | 2025 실태조사: 도입 경영체 **3,138** 중 어려움 1위 **설치비용 확보 30.1%** (2차 보도) | FETV 재인용 · `[VERIFY]` 농식품부 표 |
| **에너지·전기** | 방울토마토 스마트팜 사례: 투자 ~9억 · 연 전기 ~**7,000만** · 매출 대비 남는 것 없음 (농가 인터뷰) | [문화일보](https://www.munhwa.com/article/11512638) |

| **판매가·수급** | 생산성↑만으로 소득↑ 보장 안 됨 · 가격 하락 시 CAPEX 회수 붕괴 | FETV 등 |

**핵심:** 시설 스마트팜의 실패 모드는 “센서가 없어서”가 아니라 **고정비(자본·에너지·부채)가 농산물 마진을 초과**하는 구조다.

### 2.2 수직농장·식물공장 — 글로벌·국내 공통 `[FACT]`

| 원인 | 내용 |
|------|------|
| **전력 비중** | LED+공조로 운영비의 **상당 비중(보도상 30~40% 언급)** · “1kg 채소 전기료 ≈ 판매가” 류 증언 |
| **범용 엽채 가격경쟁** | 노지·온실 대비 **원가 우위 없음** → 상추·케일만으로는 구조적 적자 |
| **자본시장·에너지 쇼크** | 해외 수직농장 파산·축소 사례(에너지·금리) — “기술 미완성”보다 **유닛 이코노믹스** |
| **국내 대형 단지** | 하자·가동률·정책 투자 대비 성과 논란(예: 혁신밸리류 비판 보도) — **개별 사건 ≠ 전 산업 사망**이나 **경고 신호** |

### 2.3 왜 “노지 관수 IoT”와 혼동하면 안 되는가

| | 하이테크 실내/온실 | 노지 점적·관수 IoT (MKM 세그먼트) |
|--|-------------------|-------------------------------------|
| CAPEX 밴드 | 억~수십억 | **수백만~천만 원대**(벤더·채널 의존) |
| 에너지 | 냉난방·LED 핵심 | 펌프·통신 **상대적 소** (용수·전력망은 별 리스크) |
| 실패 모드 | 마진 < 고정비 | **통신 끊김·과수·오작동·채택 거부·구독 미납** |
| 성공 정의 | 연중 생산·브랜드 단가 | **노동시간↓ · 사고↓ · 기록성 · 겸업 가능** |

→ “시설이 망했으니 노지는 무조건 된다”는 **대칭 오류**. 노지는 CAPEX가 낮아 **실패 비용이 작을 뿐**, **자동으로 돈이 되는 것은 아님**.

## 4. 「기존 관수 제어기에 LLM만 붙이면 누구든」— 정확한 분해

내부 SSOT (`smartfarm_llm_vs_mkm_gate_checklist_v1.md`)와 시장 현실을 합치면:

### 4.1 실제로 “누구든” 가능한 구간 `[FACT]`

- MQTT/HTTP **스텁** · 대시보드 목업 · PDF 프로토콜 요약 · 데모 ON/OFF  
- 벤더 앱이 이미 하는 **스케줄·임계값 관수**의 UI 복제

→ 지휘관 직감의 **절반은 맞다.** 연동 PoC는 진입장벽이 낮다. gap JSON도 **「C03 MQTT · C07 LLM 데모 · C05 단순 임계값 = not_a_moat」**.

### 4.2 “누구든”이 **아닌** 구간 (여기가 상품)

| 게이트 | 왜 LLM 연결만으로 안 되나 |
|--------|---------------------------|
| 맹물·양액 **동시 OPEN** | 물리 사고 · 작물·토양 피해 |
| **stale/통신 끊김** → auto_stop | LTE·전원·GW 현실 |
| **일일·회당 상한** · rain gate | 과수·침수 |
| **릴레이 ACK** 추적 | “보냈음” ≠ “밸브가 움직였음” |
| **책임 경계** (SW vs 현장) | 보험·분쟁·대외 카피 |
| 설치·AS·용수·자가설치 | 소프트웨어 밖의 실패 |
| **지불 의사·채널** | 농협·경농이 이미 보급형으로 채움 |

**한 줄:**  
**「제어기+LLM」= 데모 상품. 「안전·로그·책임·채널이 붙은 관수 운영」= 다른 제품.**  
MKM이 이기려면 후자를 **현장 KPI로 증명**해야 하고, 전자를 마케팅하면 **시설 스마트팜과 같은 과대광고 함정**에 빠진다.

## 5. 동남아 노지 스마트팜 “세계화” — 일리 vs 환상

사업계획상 SEA는 **`[HYPO]` 로드맵만 · 미달성** (v1.2 §1.2).

### 5.1 부분적으로 일리 있는 논리 `[HYPO]` · 조건 명시

| 논리 | 지지 근거 | 한계 |
|------|-----------|------|
| 노지·소농이 다수 · 시설 CAPEX 부담 | IFAD 등: 아시아 농가 상당수 **2ha 미만** (시장조사 재인용) | “소농 = 스마트관수 구매”는 **비약** |
| 물·기후 스트레스 → 관수 관심 | Mekong/CSA 문헌 | 관심 ≠ 구매력·유지보수 |
| 얇은 IoT+서비스 모델이 하이테크보다 맞을 수 있음 | 소농 스마트파밍 리뷰: **affordability·수리·제도**가 채택 조건 | **한국 앱을 그대로 수출**할 근거 없음 |
| K-스마트팜 정책의 해외실증 지원 | 기본계획에 수출·해외실증 과제 | **수혜 주체는 통상 기자재·온실 기업** |

### 5.2 일리가 **약한**/반박되는 지점 `[FACT]`

| 장벽 | 출처 성격 |
|------|-----------|
| 태국 스마트 관수 채택 장벽: **비용·지식·지원·연결성·복잡성·토지·부채** | Chulalongkorn thesis 2024 |
| 인도네시아 소농 정밀관수: 투자·기술·제도 지원 부족으로 채택 저조 | 2025 multi-site 사례 논문 |
| 메콩: 인프라·신용·토지권·지식 지원 갭 | SEI state-of-knowledge 2024 |
| ASEAN 인증·교정 프로토콜 파편 | 시장보고서 재인용 — `[VERIFY]` |
| **MKM SEA 실적·파트너·현지화·결제·법무** | **디스크상 없음** |

### 5.3 냉정한 시나리오 표

| 시나리오 | 확률 감각 (주관·비수치) | 조건 |
|----------|-------------------------|------|
| A. 국내 1파일럿 KPI 통과 → B2B 소수 레퍼런스 → **현지 SI 파트너**로 SW 라이선스 | **유일하게 현실적 경로** | AS·언어·통신·결제 파트너 필수 |
| B. “동남아 노지 스마트팜 세계화”를 MKM이 리드 | **근거 없음** | 국내 PMF조차 전 |
| C. 시장조사 CAGR만 보고 선투자 | **실패 패턴** (시설 붐과 동형) | — |

**판결:**  
“동남아에 노지형 저가 스마트관수 **수요 공간**이 있다”는 말은 **부분 일리**.  
“그래서 **지금** MKM이 세계화한다”는 말은 **낙관·가스라이팅**.  
선행조건 = **국내 Go-Live KPI + 유료 고객 ≥1 + 안전사고 0 구간** — 그 전 SEA는 IR 워딩 수준의 `[HYPO]`.

## 6. 종합: 무엇을 하고 / 무엇을 하지 말 것인가

### 6.1 맞춘 전략 (유지)

1. **시설 하이테크와 다른 CAPEX 밴드**에 서기.  
2. **LLM 관수·수확 보장 카피 금지** (이미 Fact-Lock).  
3. **HW는 벤더 · MKM은 안전·로그·FaaS**.  
4. 노지심 선행 → 팜팜팜 (내부 판정과 일치).

### 6.2 버려야 할 착각

1. “시설이 망했으니 노지+LLM은 블루오션.”  
2. “연동만 되면 진입장벽이 없어 우리가 먼저.” → **농협·경농이 이미 보급형으로 채움.**  
3. “SEA는 규모가 크니 세계화.” → **채택 장벽이 더 큼.**  
4. “시범단지 +32% = 우리 농가 ROI.” → **전이 불가.**

### 6.3 다음 증거만 있으면 ‘위치’를 다시 쓸 수 있음

| # | 증거 | 왜 |
|---|------|-----|

| 3 | 유료 B2B 또는 B2C **실결제 ≥1** | PMF 최소 |
| 4 | (선택) 동일 스택 2번째 농장 | 재현성 |

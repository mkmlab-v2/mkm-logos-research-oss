## 1. 사업 개요 (임업 + 스마트 산림영농)

### 1.1 사업 배경

충청남도 금산군은 산간·노지 영농과 임업 후계 육성 정책이 병행되는 지역이다. 대표 이기륜은 **임업후계자**(금산군수 지정 제2026-7호, 2026-07-09) 및 **농업경영체 등록**(2026-06-19)을 확보하고, 상가리 179-1 부지(임대 2,019평, 5년)에서 **노지 산림·특용작물 영농**과 **스마트 관수 IoT**를 결합하는 파일럿을 추진 중이다.

본 사업은 **억 단위 식물공장 턴키**가 아니라, **수백만 원대 노지 관수 IoT(큐빅스 CoCoNET)** + **MKM 소프트웨어(안전 게이트·일지·대시보드)** 의 **얇은 FaaS(Farming-as-a-Service) 레이어** 모델이다.

### 1.2 사업 목적

| 구분 | 목적 |
|------|------|
| **현장(Phase 1)** | ~300평 노지 파일럿에서 **6채널 관수·토양 센서·안전 인터록**을 실증하고, 두릅·잎들깨 등 **임업·특용작물** 수익 기반을 마련 |
| **Track A — 노지심** | 노지·임업·겸업 농가에게 **관수 안전·일지·기록성** SaaS 제공 (B2B/B2G) |
| **Track B — 팜팜팜** | 수도권 도시 거주자에게 **가상 구획·영농 일지·컴플라이언스 팩** B2C 구독 제공 |
| **장기 [HYPO]** | 동일 SW 스택을 **동남아 노드 스마트팜**으로 확장 (로드맵만, **미달성**) |

### 1.3 사업 모델 요약

```

  큐빅스 IoT 6ch ──MQTT/HTTP──►  안전 게이트 · 일지 · 대시
         │                              │
```

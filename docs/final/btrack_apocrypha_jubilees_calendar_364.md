# B-Track Apocrypha — 희년서(Jubilees) 364일 달력·시간관

**역할**: 외경 전용 NotebookLM 노트에 **결정론적 절기·달력** 논지를 제공. B-Track 연구용. A-Track·실매매와 무관.

## 요약 (영문 위키백과, Book of Jubilees)

희년서는 **제6장**에서 연 **364일** 연간 달력을 고수한다: 네 분기 각 **13주**로 구성되며, 12개 음력월의 해가 아니라고 하며 연간 약 **10일**의 오차를 지적한다(실제 천문학적 오차는 약 11¼일에 가깝다는 설명이 학술 요약에 따름). “Double Sabbath”을 연간 하루로 계산하는 등의 계산 방식도 언급된다.

출처: https://en.wikipedia.org/wiki/Book_of_Jubilees (접근일 기준 본문 요약; 정식 인용은 학술 번역본·비평 문헌과 대조)

## 신학·문헌 키워드

- 성전·예루살렘 절기 체계와의 **긴장**(쿰란 문헌과의 관계는 별도 연구 주제).
- **하나님이 정한 시간표**에 대한 자신감(절기·안식·희년 구조).

## 원문 정독 시

학술 번역본(VanderKam, Wintermute 등) 또는 게즈어(Geʻez) 비교는 도서관·판권 정본을 따른다. 본 MD는 NotebookLM 질의용 **개요 고정**에 쓴다.

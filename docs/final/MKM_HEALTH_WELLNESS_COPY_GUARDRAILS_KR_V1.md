## 1) 블랙리스트 (대외 카피·UI·유료 리포트 본문 — 기본 금지)

| 금지/고위험 표현 (KR) | 이유 (요지) |
|----------------------|-------------|
| 진단, 확진, 처방, 치료, 처치, 처방전 | 의료행위·의료광고로 읽힐 수 있음 |
| 한의사 진단, 한의학적 진단, 체질 진단 | 임상 진단과 동일시 위험 |
| ○○% 정확도, 민감도·특이도 (근거 패키지 없이) | 과장·허위광고·오인 가능 |
| 100% 안내, 완치, 부작용 없음, 무조건 | 절대적 보장으로 읽힘 |
| 암·당뇨·고혈압 등 질병명 + 개선·치유·제거 | 건강기능식품·일반 서비스와 혼동 |
| 의약품·의료기기와 동등·우월 주장 | 의료법·약사법·부당광고 리스크 |
| 미승인 의료기기·원격 진료 인상 | 허가 범위 밖 표현 주의 |

**영문 혼용 시:** cure, diagnose, treat, prescription, clinical accuracy (without IRB-grade pack) — 동일 취급.

## 2) 그레이존 (조건부만 — 법무 승인·면책·범위 문구 필수)

| 표현 | 조건 |
|------|------|
| 설문, 자가 점검, 라이프스타일 패턴 | 결과를 **“참고”**로만; 진단·치료 연결 문구 금지 |
| 체질, 사상(四象) | **문화·은유·비임상** 명시; 개인 결과를 **의학적 체질**로 단정 금지 |
| 확률·점수·밴드 | **정의(입력·모델·한계)** 공개; 대외 **“목표 정확도”** 숫자는 임상 근거 없이 쓰지 않음 |
| 한의·경락·한약 | **교육·역사** 한정; 특정 처방·복용 지시 금지 |

## 4) 개인정보·민감정보 (건강 설문과 결합 시)

- **최소 수집**: 질문 수·필드는 “초개인화”와 트레이드오프 — **목적 명시·동의·보유 기간** 문서화.
- 건강·증상 상세는 **특수 민감정보**에 가까움 → 별도 동의·암호화·접근통제·삭제 요청 경로.
- **재식별 방지**: 공개 쇼룸·샘플 리포트는 질문 원문·생년·증상 금지; 집계·토픽만.

## 5) ML·“정확도” 대외 표기 규칙 (Fact-Lock 정신)

- 대외: **검증된 리포트·코호트·프로토콜 ID**가 있을 때만 수치 언급.
- 내부 목표(예: 70%)는 **내부 OKR**로 두고, 마케팅 카피와 **분리**.
- 설문→라벨이 있으면 **윤리·동의·편향·금기** 문서를 산출물과 함께 관리.

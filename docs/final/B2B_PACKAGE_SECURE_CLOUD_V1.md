## 1) Audience

- Security operations platform teams
- Sovereign/private AI infrastructure providers
- Compliance and reliability owners

## 2) Core Message (Fact-Safe)

Reduce plaintext exposure surface and conditional transport cost with policy-driven routing, while enforcing automatic safe fallback under health alerts.

## 3) Security KPI Lens

- Primary:
  - safe-path continuity (`track_a_primary` fallback)
  - alert-to-guard reaction correctness
  - decision/audit artifact completeness
- Secondary:
  - candidate-ok rate
  - unresolved token trend
  - forced-drill pass status

## 4) Security-specific Success Criteria

- Alert trigger correctly forces guarded downgrade
- Guard drill passes with evidence artifact
- Runtime config is generated from guarded decision only
- Daily report and alert artifact chain remains intact
